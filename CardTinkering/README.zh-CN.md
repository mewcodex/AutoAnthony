# Auto-Anthonyology: Card Tinkering

这是 Auto-Anthonyology 的衍生模组。在每一幕 Boss 前增加一个受 Noita 圣山启发、使用问号图标的独立训练室节点。Boss 和先古之民节点都继续使用本体的特殊节点外观。

当前实现：

- 新增可选的“创造卡牌”：从卡组页面的独立按钮进入，左侧用卡色、组件类别两层标签筛选本体完整组件目录；左键单选、右键多选，组件可无限复制，关键字同样作为可拖拽条目。
- 创造卡牌允许调整牌色、稀有度、类型、能量/蓝星费用，并可双击组件修改其结构化数值；仍实时显示本体算法给出的组件价值和预算/容量，但允许超出容量，只有违反组件组合规则时才禁止生成。
- 在训练室、随时编辑和创造卡牌中右键当前卡面，可按当前效果重新随机卡名与卡图；先古卡只会使用对应角色的先古卡图，训练室方案与重置也会一并保存或恢复这份显示身份。
- 创造的卡牌支持带版本号的字符串导入/导出和批量生成。改变类型时，被本体规则明确判为冲突的组件会移入临时区；把已安装组件或关键字拖回左侧目录则会删除。
- 本体公开拆解目录中能够精确重建的原版卡会直接进入训练室和随时编辑；保存时才替换该单卡实例，并保留升级、附魔、腐化、永久成长和本地关键字状态。
- 原版牌中自行完成随机生成或选牌的组件按其空 `CardTargetSlot` 结构处理，不再被误认为缺少外置选择器；该规则覆盖完整原版拆解目录，而非按卡名例外。
- 只允许编辑 Auto-Anthonyology 生成的随机卡；费用、蓝星费用、类型、稀有度和关键词属于不可拆卸的卡牌外壳。
- 每张生成卡在当前价值到同生成逻辑普通上界之间确定独立容量，并随存档固定；普通上界外的彩蛋卡标记为“永恒”且不可编辑。
- 组件保留自己的固定数值、衍生牌/球槽位、独立升级状态与永久成长记录；跨卡移动不会跟随目标外壳错误升级或降级。
- 可把组件拖入背包或语法兼容的卡牌槽位；条件/触发器拥有缩进的子槽位。拖动保留鼠标指针，不再绘制箭头或目标框。
- 卡牌关键字以不可拆卸的假组件显示在效果列表首尾；把真实组件拖到另一个组件上会插入到它之前。
- 训练室内提供“重置”“保存方案”“加载方案”；方案可以保存不合法草稿，“保存并完成”会对不合法牌组显示红色确认。
- 在东尼算法设置中开启“随时编辑”后，可从战斗外的卡组页面进入同一工匠台；战斗奖励页同样可用，且不会消耗本幕训练室。
- 可在同一设置页开启“忽略容量限制”：预算与容量仍会实时显示，但容量溢出不再令卡牌失效；组件兼容性和卡牌结构规则不受影响。
- 训练事件会自动打开工匠台；若界面被其它模组延迟，事件选项“打开卡牌工匠台”可再次触发。
- 治疗、最大生命与永久成长组件按“单次”处理；首次生效后保存为灰色，永久成长本身继续保留并随组件移动。
- 本体标记为 `SinglePerCard` 或 `UniquePerPool` 的组件会在编辑器中显示“整卡唯一”，并继续由本体组合规则禁止同牌重复。
- 训练室、随时编辑入口均跟随东尼算法设置页顶部的总开关；关闭时仍保留存档数据，避免既有卡牌状态丢失。
- 卡组栏使用三列加宽布局并保留选择前的滚动位置；当前卡预览顶部对齐，价值块缩小；组件标签区分正面价值、触发倍率、整卡全局负面倍率与线性负代价。
- 当前草稿即使暂时不合法或超过容量也继续渲染完整卡面；方案保存允许保留这类草稿，保存并完成时给出红色二次确认。
- 整卡预算、组件价值、线性代价、全卡倍率、有效费用与 X 端点均直接取自本体 Card Tinkering API；读档归一化不会再用当前卡牌价值悄悄抬高既有容量。
- 子组件显示自身局部价值，外层触发次数只在对应触发器上显示；空触发器也按本体实际挂载后的结算口径显示，因此不会在加入第一个后续时跳变；放置、取消或原位拖回组件后会立即清除全部插槽高亮。
- 创造卡牌的关键字目录会隔离尚不适用于当前牌壳的估值前提；奇巧在加入时会归一化到合法印刷费用，切换到不兼容费用时会自动移除，不再令整个目录中断渲染。
- 内部存档载体不会再作为 Modifier 图标显示在顶部栏。
- 联机模式会为每名玩家打开各自的训练室编辑器；保存通过原版事件选择协议同步完整牌组，组件背包和每幕完成状态按玩家分别保存。工作台会跨帧等待各客户端的房间 UI 就绪；每名玩家完成自己的编辑后，由原版联机地图流程协调继续。
- 检测到 Chimera 模组已加载且当前为 Chimera 局时，本扩展会整局停用：不生成或接管训练室，不提供卡组编辑入口，也不读写组件状态或改动卡牌的描述、升级与战斗行为；普通角色局不受影响。

“随时编辑”和“创造卡牌”目前仍只在单人模式显示：这两个入口不处于原版事件/行动队列的同步边界内，联机开放会让牌组或战斗牌堆只在本地变化。训练室本身已支持联机。

构建与安装：

```powershell
.\CardTinkering\build.ps1 -GameDir "你的 Slay the Spire 2 目录" -Configuration Release
```

本模组依赖 Auto-Anthonyology 0.3.94 或更高版本；创造卡牌与原版卡拆解入口使用本体提供的公开 API。先安装基础模组，再把
`CardTinkering/build/AutoAnthonyCardTinkering` 文件夹放入游戏的 mods 目录。
