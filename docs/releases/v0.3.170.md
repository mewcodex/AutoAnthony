# Auto-Anthonyology 0.3.170 — STS2 v0.114.0

Requires Slay the Spire 2 **v0.114.x**. The download contains `AutoAnthony.dll`, `AutoAnthony.json`, and
`AutoAnthony.pck`; extract the `AutoAnthony` folder into the game's `mods` directory.

- Updated runtime integration for v0.114.0 and migrated removed native APIs.
- Updated the Fool's new/reworked cards, component descriptions, native values, rarity/cost data, keywords,
  and upgrade bindings, including Twin Shot, Optimism, Florescence, Growth, Tune, and Recall.
- Preserved older generated effects and saved card identities when their original source effects were removed.
- Includes the v0.3.166–169 potion-event, disabled Colorless library, Arrow-damage generation, and Shoot-tag fixes.

Existing public API versions and the snapshot schema are unchanged. Other installed mods need their own v114
compatibility updates; the locally available RitsuLib 0.6.15 still fails its v113 AttackHitHook patch on v114.

## 简体中文

适用于《杀戮尖塔 2》**v0.114.x**。将压缩包中的 `AutoAnthony` 文件夹解压到游戏 `mods` 目录。

- 适配 v0.114.0，迁移被原版移除的接口。
- 更新愚者新增和重做卡牌的组件、描述、数值、稀有度、费用、关键词及升级，包括双重射击、乐观、怒放、生长、调音和召回。
- 保留旧存档中已生成的旧版效果与卡牌身份。
- 包含 0.3.166–169 的药水事件、关闭模组时的无色图鉴、射击数值及发射标签修复。

公开 API 版本及快照格式不变。其它模组需要各自适配新版；本地现有 RitsuLib 0.6.15 的 v113 攻击钩子仍会在 v114 报错。
